# Organize workstreams

Group tasks by durable outcome rather than team or technology. Give each workstream a measurable result, owner role, dependencies, active milestone, risks, and done criteria.

Keep cross-workstream dependencies explicit and avoid duplicating tasks. Flag milestones whose completion depends on an unresolved approval or external state.

Return the proposed hierarchy and explain any move that changes existing progress reporting. Do not silently rewrite existing plans.

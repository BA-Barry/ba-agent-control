# Prepare a release candidate

Confirm the version, supported targets, release notes, full test receipts, installation and rollback steps, data-retention behavior, third-party license inventory, and artifact checksums.

Build only local release-candidate artifacts unless the user has separately authorized external publication. Push, tag, publish, deploy, and credential registration remain approval-gated.

Return the candidate inventory, verification evidence, unresolved risks, and the precise approval needed for any external next step.

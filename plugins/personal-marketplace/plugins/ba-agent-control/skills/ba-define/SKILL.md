# Define a requirement

Translate the request into an outcome, in-scope and out-of-scope behavior, constraints, acceptance criteria, evidence to retain, and decisions that need the user.

Inspect relevant repository context before inferring technical constraints. Mark assumptions and uncertainty. Ask only when a missing decision would materially change architecture, data, permissions, licensing, or user-visible behavior.

Do not implement, dispatch, or expand the product scope. Return a definition ready for planning.

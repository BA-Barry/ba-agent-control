# Review task output

Compare the implementation and diff with the approved requirement, design, declared paths, and acceptance criteria. Inspect relevant tests and runtime evidence.

Lead with actionable findings ordered by impact. Include file or artifact references and a concrete failure scenario. Separate blocking defects from non-blocking improvements; omit style preferences without behavioral impact.

If there are no findings, state residual risks and verification gaps. Do not approve completion when required evidence is missing.

# Console surface brief

- Scope: the embedded BA Agent console, starting with overview and extending to all seven operating surfaces.
- Mode: Operate.
- Audience/job: an advanced individual developer coordinating several local repositories and up to four concurrent Codex agents.
- Primary task: understand project health and required action within seconds, then move from workstream planning into a run, approval, gate, or receipt without losing context.
- Content: real persisted entities when available; clearly labeled synthetic demonstrations during greenfield development.
- Constraints: Chinese first with complete English; light/dark/system; WCAG 2.2 AA; high information density; no embedded shell; Radix + one semantic token system; restrained state-driven motion.
- Chosen direction: surveyor's field book, explicitly confirmed by the user after reroll seed `8addc9b7`; comp-first. The user approved an A+B composition on 2026-08-24: A's control-point traverse and right closure ledger, combined with B's fixed event and quality evidence register.
- Memorable moment: repositories act as control points, isolated worktrees as traverse points, and a task closes only when gate evidence and the receipt chain resolve its visible closure error.
- First viewport: a project control-point index at left; a continuous traverse record connecting milestones, tasks and four runs above an append-only event/evidence register; approvals and closure error at right.

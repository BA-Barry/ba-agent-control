## Sampled visual system

- Page ground: `#f3f0e6`
- Dark index field: `#202722`
- Operational route ink: `#2b675b`
- Capacity/brass accent: `#b57a2a`
- Approval/error stamp: `#a3453f`
- Footer/deeper paper field: `#e7e1d2`
- Typography: compact workhorse Chinese UI sans for language; tabular monospace only for task codes, hashes, timestamps, measurements and runtime state.
- Corners/elevation: square to 2px operational controls; no card radius system; floating station labels use one soft downward shadow without a competing border.
- Rules: 1px graphite separators, 2px only for the dominant traverse, evidence-register boundary and selected control-point datum.
